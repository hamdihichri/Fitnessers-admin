Place your 512×512 PNG icon file here named `icon.png`.

electron-builder will automatically convert it to the appropriate format:
- Windows: .ico (multi-size)
- macOS: .icns
- Linux: .png

Requirements:
- Minimum size: 512×512 px
- Format: PNG with transparency supported
- Name: icon.png

You can generate one at: https://www.iconcraft.dev or https://icon.kitchen
